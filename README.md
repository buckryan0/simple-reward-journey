# Reward Steps

Create a simple landing page with a centered layout. Add a blank gift card style image at the top with no logo or brand name. Below it, include a neutral headline about following steps to receive a reward. Add a step-by-step list with exactly these 4 steps:

﻿﻿﻿Click the button below

﻿﻿﻿Enter your email & basic info

﻿﻿﻿Complete 3 to 5 required deals

﻿﻿﻿Receive your reward once verified

Place a large call-to-action button below the steps with the text "Get Started". Add a small neutral note under the button - Available in selected countries - US, UK, AU, CA

Keep the design minimal, clean, and mobile-friendly. Do not use words like free, limited time, instant, guaranteed, or any urgency-based language. Do not add extra steps, sections, navigation menu, or footer.
